# Gurkan_AI

A comprehensive local AI automation and data processing ecosystem. This project integrates local LLMs (via LM Studio) to automate content generation, data extraction, and system tasks.

## 🚀 Features
- **Local LLM Integration:** Connects with LM Studio for private, local AI processing.
- **Data Automation:** Scripts to fetch, extract, and process data (CSV, TXT).
- **Jarvis Assistant:** Experimental voice and screen analysis modules.
- **Automated Workflows:** Scripts for generating notes, managing catalogs, and archiving data.

## 📁 Project Structure
- `/Gurkan_AI_Kodlar`: Core Python scripts for various AI and automation tasks.
- `*.csv`: Catalog and data files used by the scripts.
- `*.md`: Documentation and setup guides.
